    Нейросети в сети

    Узел Устройство Скорость Свободно Держит слои

    Ни один узел не обслуживает нейросети. Запустите узел с флагом -llm.

    Выберите модель и напишите сообщение. Ответ считают узлы сети: каждый — свой кусок слоёв.

    Загрузить модель с Hugging Face

    rakkan-web скачает файлы модели и передаст их узлу; узлы с -llm потом возьмут себе её слои. Подходят Llama 3, Qwen2/2.5 и Qwen3 в safetensors, а также DeepSeek-V4.1.
