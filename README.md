# Rakkan Mesh

Отказоустойчивая и безопасная mesh-сеть для распределённых вычислений.
Код задач передаётся как WebAssembly и исполняется на узлах в песочнице.

Статус: ранняя разработка. Сейчас работает локальная песочница.
Архитектура и план — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

```sh
go test ./...
CGO_ENABLED=0 go build ./cmd/rakkan-node   # статический бинарник рекомендуется
./rakkan-node run -input data.bin -mem 64 -gas 1000000000 -timeout 5s task.wasm
```

Задача исполняется в изолированном воркер-процессе (`-isolation strict`: namespaces,
seccomp, без capabilities). `-cgroup self` добавляет лимиты памяти/CPU через cgroup v2,
если узлу делегирована cgroup. Подробности — в разделе об изоляции в
[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## ABI задачи

Модуль экспортирует `memory` и функцию `run: () -> i32` (0 означает успех) и может
импортировать только модуль `rakkan`:

| Функция | Сигнатура | Назначение |
|---|---|---|
| `input_len` | `() -> i32` | размер входа |
| `input_read` | `(dst, offset, len) -> i32` | скопировать часть входа в память, вернуть число байт |
| `output_write` | `(src, len)` | дописать в выход |
| `log` | `(src, len)` | диагностический лог (обрезается по лимиту) |

Имена с префиксом `__rakkan_` зарезервированы. Исполнение ограничено детерминированным
gas: одинаковый модуль с одинаковым входом тратит одинаковый gas на любом узле.
