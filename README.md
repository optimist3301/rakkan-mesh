# Rakkan Mesh

Отказоустойчивая и безопасная mesh-сеть для распределённых вычислений.
Код задач передаётся как WebAssembly и исполняется на узлах в песочнице.

Статус: ранняя разработка. Работают песочница с изоляцией процессов, закрытая
сеть (сертификаты, обнаружение, обход NAT, восстановление, отзыв) и
распределённое исполнение задач с повтором при сбоях и проверкой результата
репликами. Из Node.js — через [`sdk/js`](sdk/js).
Архитектура и план — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

```sh
go test ./...
CGO_ENABLED=0 go build ./cmd/rakkan-node   # статический бинарник рекомендуется
./rakkan-node run -input data.bin -mem 64 -gas 1000000000 -timeout 5s task.wasm
```

Задача исполняется в изолированном воркер-процессе (`-isolation strict`: namespaces,
seccomp, без capabilities). `-cgroup self` добавляет лимиты памяти/CPU через cgroup v2,
если узлу делегирована cgroup. Подробности — в разделе об изоляции в
[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## ABI задачи

Модуль экспортирует `memory` и функцию `run: () -> i32` (0 означает успех) и может
импортировать только модуль `rakkan`:

| Функция | Сигнатура | Назначение |
|---|---|---|
| `input_len` | `() -> i32` | размер входа |
| `input_read` | `(dst, offset, len) -> i32` | скопировать часть входа в память, вернуть число байт |
| `output_write` | `(src, len)` | дописать в выход |
| `log` | `(src, len)` | диагностический лог (обрезается по лимиту) |
| `blob_count` | `() -> i32` | число прикреплённых блобов |
| `blob_size` | `(index) -> i64` | размер блоба, −1 если нет такого |
| `blob_read` | `(index, dst, offset i64, len) -> i32` | прочитать кусок блоба в память; узел докачивает только читаемые чанки |

**Image kernels** (`rakkan_image_v1`, capability `image/1`): нативная обработка
изображений внутри изолированного воркера. Изображения — дескрипторы в таблице
хоста; функции возвращают дескриптор или число байт, отрицательное — код ошибки.

| Функция | Назначение |
|---|---|
| `decode_input()`, `decode_blob(i)`, `decode(src, len)` | PNG/JPEG → дескриптор (размеры проверяются до декодирования) |
| `create(w, h)`, `width(h)`, `height(h)` | новое изображение, размеры |
| `resize(h, w, h)`, `fit(h, max_w, max_h)`, `crop(h, x, y, w, h)` | масштабирование (целочисленный box-фильтр), вписывание, обрезка |
| `grayscale(h)`, `blur(h, r)` | оттенки серого, размытие |
| `pixels_read(h, dst, len)`, `pixels_write(h, src, len)` | RGBA8 в память задачи и обратно — для своих алгоритмов |
| `encode_output(h, format, quality)` | PNG (0) или JPEG (1) — сразу в выход задачи |
| `free(h)` | освободить |

Пиксели всех изображений задачи ограничены её лимитом памяти, gas списывается
за пиксель; результат побайтово одинаков на любой архитектуре.

Имена с префиксом `__rakkan_` зарезервированы. Исполнение ограничено детерминированным
gas: одинаковый модуль с одинаковым входом тратит одинаковый gas на любом узле.
